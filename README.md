# Masjid Ulul Albab v2

Website resmi Masjid Ulul Albab untuk memberikan informasi dan layanan kepada jamaah.

### Development

```bash
npm run dev          # Jalankan development server dengan Turbopack
npm run build        # Build untuk production
npm run start        # Jalankan production server
```

### Code Quality & Testing

```bash
npm run lint         # Jalankan ESLint untuk pemeriksaan kode
npm run type-check   # Jalankan TypeScript type checking
npm run build:check  # Periksa build tanpa linting
```

### Code Formatting

```bash
npm run prettier     # Format kode agar konsisten dan rapi
```

## Verify Code

Untuk memastikan kode berkualitas dan bebas dari error, gunakan perintah:

```bash
npm run verify
```

## Formatting Kode

Untuk menjaga konsistensi format kode, gunakan:

```bash
npm run prettier
```
